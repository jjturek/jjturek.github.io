Moose MCP privacy policy

Effective 28 October 2026.

Moose MCP is a connector, run on its user's own computer, that lets an AI assistant (Claude, by Anthropic) act in that user's Google account on the user's instruction. Its only user is its operator, John Turek. This policy describes what Google user data it accesses and what happens to that data. See the Moose MCP home page for what the app does.

Data accessed

Moose MCP requests the following Google permissions. Each is used only to carry out a task the user has asked the assistant to do.

PermissionUsed to
Google Docs documentsread, create and edit the user's documents
Google Drive drive, drive.filefind, read, create, move and comment on the user's files
Google Sheets spreadsheetsread and edit the user's spreadsheets
Google Slides presentationsread, create and edit the user's presentations
Gmail gmail.modifyread messages the user points to, and create, update and delete email drafts; the app does not send email
Google Calendar calendar.eventscreate and update events in the user's calendar
Apps Script script.external_requestrun the user's own scripts that call external services

How the data is used

Google user data is read only when the user asks the assistant to do something that needs it, and only to the extent that task needs. It is not used for advertising, profiling, or any purpose other than the user's own task, and it is not sold.

Where the data goes

  • The connector runs on the user's computer. Its access token is stored there and nowhere else.
  • Content the assistant reads to complete a task is sent to Anthropic, the provider of the AI model, as part of that task. Anthropic's handling of it is governed by Anthropic's privacy policy.
  • Google user data is not shared with, transferred to, or disclosed to anyone else.
  • Google user data is not used to develop, improve or train generalised AI or machine-learning models.

Retention and deletion

Moose MCP keeps no copy of Google user data beyond what a task produces in the user's own Google account or on the user's own computer. The user can revoke Moose MCP's access at any time at myaccount.google.com/permissions, which ends all further access; deleting the token file on the user's computer has the same effect.

Limited Use

Moose MCP's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
